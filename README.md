# Paediatric surgeon demo site

One-file website. Open `index.html` in any browser to see it.

## Swap in real content
- Images and videos: generate from `PROMPTS.md`, drop them into `assets/` with the exact filenames (images are .webp now). They appear on their own.
- Everything marked sample must be replaced before going live: the doctor's name (Dr. Asha Varma is fictional), the numbers (4,200+, 70%, 18 yrs), hospital names, phone, address, and qualifications.
- The booking form is demo only. Connect it to Formspree, Google Forms or WhatsApp before launch.
